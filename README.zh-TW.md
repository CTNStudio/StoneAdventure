## 這是什麼

一款持續更新的 Minecraft 基岩版附加包。我們不改變原版的生存節奏，只是讓腳邊那些沒人要的圓石，突然變得有用。

在這裡，你靠挖石頭和討伐石類生物累積石頭與壓縮石頭，一路升級工作台、護甲與武器；同時，幽暗的礦洞與漆黑的夜晚也不再安全——石類生物會找上門來。

> 「逐漸深入，汝將窺見真知」

---

## 內容亮點

- **石頭即貨幣**：挖到的每一塊圓石都能變成戰力，箱子裡的石頭從此不再浪費
- **五級壓縮體系**：九石合一，最高五級壓縮石頭，是全部裝備的根基
- **鑲髓石珠**：二十餘種可鑲嵌的石珠，武器護甲各有著重，自由搭配流派
- **磐石大典**：章節式任務 + 成就 + 商店三合一，手把手帶新人入坑
- **石源與週常**：出售石幣換石源，每週三個週常任務，稀有物資有處可換
- **石心系統**：獨立於血條的第二條命，脫戰自動恢復
- **石潮事件**：擊敗 BOSS 後，每個週末的夜晚都可能被石類生物圍攻
- **豐富的 BOSS**：石之圖騰、高塔餘裔……每一個都是不同的戰鬥體驗
- **戰鬥高塔**：逐層推進的試煉場，塔頂鎮守著高塔餘裔
- **磐石荒地**：全新群系，藏著古文明的秘密
- **多語言**：简体中文 / 繁體中文 / English / Русский

## 新手入門

整個流程可以概括成五步：

1. **採石**：挖圓石、深板岩，或者討伐石類生物，得到**石頭**與**石粒**。
2. **壓縮**：9 個石頭合成 1 個一級壓縮石頭，9 個一級合成二級，以此類推最多到五級；四級以上需要**石頭工作台**。
3. **升級**：用壓縮石頭做工具、武器和盔甲，等級越高，強度越高。
4. **深入**：帶著新裝備去磐石荒地、廢棄驛站、戰鬥高塔，收集石髓、鑲髓石珠與擴容石板。
5. **挑戰**：湊齊血祭之瓶，召喚 BOSS**石之圖騰**；擊敗它之後，世界會記住你——石潮開啟。

一路走下去，記得隨時翻開**磐石大典**，它會告訴你下一步該做什麼。

## 玩法系統

### 物品

物品構成了這個組件的主體，幾乎所有物品都與石頭掛鉤。

- **石質工具與武器**：斧、鎬、鍬、鋤、劍系列全面覆蓋，並會跟隨 Minecraft 新版本更新；此外還有錘、矛、彈弓與多功能工具。
- **石質盔甲**：用不同等級的壓縮石頭合成，等級越高防護越強；四級及以上同樣在**石頭工作台**中製作。
- **更多食物**：石頭麵包、石頭蘋果、石頭胡蘿蔔、石頭西瓜片……還有石力架。
- **更多物品**：石粒、藏生之石、熔岩餘骸、石髓、鑲髓石珠、擴容石板、石幣等。

> **小提示**：五級壓縮石頭製品不會被燒毀，掉進岩漿裡也不用慌。

### 方塊

在這裡，石頭不再是墊腳石，而是實打實的資源。

- **壓縮石頭**：共五個等級，逐級合成，高等級需要通過石頭合成台。
- **工作類方塊**：石頭工作台負責高階合成，石頭轉換台負責壓縮石頭的升降級，石頭鍛造台用於改造裝備。
- **礦物**：石髓礦石與深層石髓礦石，埋藏於地下的稀有礦物；時運附魔對其有效。
- **擬造石華**：用新生之石種下的活體方塊，成熟的擬態石華被破壞後有機率掉落葬生之石。

### 磐石大典

這是組件的**任務書兼成就冊**，也是新人的嚮導，更是整個玩法循環的骨架。

- **章節任務**：從採石、壓縮起步，逐步推進到探索、戰鬥與 BOSS 挑戰；進度自動追蹤，達成後自動提交，獎勵回書裡領取。
- **成就系統**：獨立於任務的長期目標，需要手動領獎。
- **商店**：用**石源**兌換石幣、鑲髓石珠、擴容石板、石頭之星等稀有物資。
- **設置**：可切換石心顯示模式；若遇到 UI 閃爍或 action bar 不顯示，切到**聊天欄模式**即可。

> 也可用指令 `/sab` 直接打開磐石大典。

### 石幣、石源與週常

石頭世界也有自己的經濟體系：

- **石幣**：基礎流通貨幣，用於和**石頭行商**交易。
- **石源**：某種意義上的「魔力值」，在磐石大典出售石幣、完成週常、達成都可獲得，是換取稀有物資的有效途徑。
- **週常任務**：每個遊戲週隨機刷新三個，全部完成還有額外獎勵。

### 石心與石潮

**石心**——獨立於血條之外的第二條命：

- 擊敗小 BOSS**高塔餘裔**掉落石心，食用後獲得 **4 顆石心**。
- 受到傷害時石心先行抵擋；脫戰 5 秒後緩慢恢復，不受飢餓值影響。
- 顯示模式可在磐石大典設置中切換（UI / 聊天欄）。

**石潮**——你擊敗 BOSS 之後，世界給你的「回禮」：

- 首次擊敗**石之圖騰**後開啟。
- 每個遊戲週的**週末夜晚**有 30% 機率爆發。
- 爆發時會在玩家周圍刷新大量石頭生物。
- 石潮期間**無法睡覺**。

### 生物圖鑑

- [石頭守衛](https://www.mcmod.cn/item/695533.html)：石類生物，攻擊造成緩慢效果。
- [石頭弓箭手](https://www.mcmod.cn/item/695532.html)：遠程攻擊，可掉落箭矢，擁有砂岩、深板岩等多個變種。
- [石頭行商](https://www.mcmod.cn/item/698394.html)：中立生物，可用石幣交易。
- **石頭傀儡**：會分裂出石頭守衛（已削弱，無法無限召喚）。
- **石頭浪者**、**迸裂石殼**：常見的石類敵對生物，石潮的主力。
- **流浪收藏家**：遊蕩的商人，交易內容經過多次平衡。
- **掠寶者**：屬於掠奪者陣營但不會參與襲擊，在平原的營地遊蕩，會攻擊村民、流浪商人、流浪收藏家以及你。
- **幽匿石像**：刷新於深暗之域，隱匿在幽匿方塊中，靠近後召喚石頭傀儡。
- **高塔餘裔**：小 BOSS，生成於戰鬥高塔頂端，二階段移速加快並獲得 40% 減傷。
- **石之圖騰**：BOSS，兩個階段、四種形態。

此外還有**苔石守衛**、**砂岩守衛**、**熔鑄石頭傀儡**、**遠古石頭守衛**等變種；遊戲內的**生物志**會記錄你的擊殺與發現。

![生物圖](https://s41.ax1x.com/2026/08/30/pnP42xe.png)

### 建築與結構

- **石頭刷怪籠**：6 個變種，分佈在不同的地層。
- **廢棄驛站**：探索有風險，收益也豐厚。
- **掠寶者營地**：掠寶者在平原駐紮。
- **石頭堡壘**：成規模的石造要塞，物資與危險並存。
- **古石祭壇**：位於磐石荒地，二層有獻祭短刀，一層有血祭石柱。
- **血祭堡壘**：地下堡壘，頂部自帶五級壓縮石頭與激活的血祭石柱，可免獻祭直接召喚 BOSS。
- **石之戰鬥高塔**：共八層，塔頂鎮守著高塔餘裔。

![建築](https://i.imgs.ovh/2026/08/30/f89a426986970139b0ce21e956b78a25.png)

### BOSS：石之圖騰

兩個階段，各 **300 點生命**，每秒自然回復 1 點——拖得越久越吃虧。

- **第一階段**：外殼極其堅硬，**只有鎬子能造成傷害**，會釋放衝擊波、召喚石頭傀儡。
- **第二階段**：解鎖瞬移，並擁有四種形態，每 15 秒依次輪換：
  - **棘沼**：喚魔者尖牙、中毒衝擊波、召喚苔石守衛。
  - **戰狂**：四連發火球、召喚熔鑄石頭傀儡；最後 3 秒發動**極怒之吼**，對 8 格內生物造成高頻傷害與擊退。
  - **荒蕪**：施加失明，召喚較多砂岩守衛，攻擊附帶飢餓。
  - **終末**：龍息火球，瞬移能力大幅加強。

**召喚流程**：古石祭壇二層取**獻祭短刀** → 玻璃杯 + 短刀扣血得**血瓶** → 合成**赝血祭瓶** → 用**石頭之心**在釀造台釀成**血祭之瓶** → 右鍵**血祭石柱**使其激活並挖下 → 下方兩塊**五級壓縮石頭**、上方放激活的血祭石柱（同雪傀儡搭法）。

> 嫌麻煩？去**血祭堡壘**，那裡的祭壇已經搭好了。

### 群系：磐石荒地

地表由圓石構成。這裡是**古石祭壇**的所在，也是石髓礦較為富集的地方——想湊齊召喚 BOSS 的材料，多半要在這兒待上一陣。

## 安裝

1. 前往 [Releases](https://github.com/CTNStudio/StoneAdventure/releases) 下載最新的 `.mcaddon`。
2. 雙擊自動匯入，或在遊戲內透過「設定 → 儲存 → 匯入」完成。
3. 新建世界，在世界設定中**同時啟用行為包與資源包**。
4. 確認遊戲版本為 **1.26.40 及以上**，否則行為包會載入失敗。
