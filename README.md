## 作品介绍

欢迎游玩石头工艺&磐石之旅——一款持续更新的实用兼冒险类Minecraft附加包！我们欲在不影响原版游戏进程的前提下进行游戏内容的拓展，带来更丰富的游戏体验。在这里，你需要通过不断挖掘石头或者讨伐石类生物以获得石头以及压缩石头，并通过不断升级工作台以获得更高级的护甲及武器。同时，一些挑战也将袭来——在幽暗的矿洞中以及漆黑的夜晚，石类生物将会出现并对你构成威胁。

> “逐渐深入，汝将窥见真知”

## 物品系统

我们拥有大量关于石头的物品。你可以通过不断挖掘石头或者讨伐石类生物以获得石头以及压缩石头。物品构成了这个组件的主体，几乎所有物品与石头挂钩。

- **石质工具与武器**：斧、镐、锹、锄、剑系列工具全面覆盖，且会跟随Minecraft新版本更新。此外，还有锤，多功能工具等工具任君使用。
- **石质盔甲**：使用不同等级的压缩石头合成压缩石盔甲，获得更强的防护能力。
- **更多食物**：石头面包，石头苹果，石头胡萝卜，石头西瓜片……还有石力架！铁齿铜牙史蒂夫说是（
- **更多物品**：石粒、藏生之石、熔岩余骸、石髓、镶髓石珠、扩容石板等。功能各异，待你发现。

## 方块系统

方块也是这个组件的重要组成部分。在这里，石头不再是垫脚石，而是及其实用的资源。

- **压缩石头**：共五个等级，逐级合成，高等级压缩石头需要通过石头合成台合成。
- **工作类方块**：石头工作台，石头转换台和石头锻造台各司其职，功能丰富。
- **矿物**：石髓矿石，埋藏于地下的稀有矿物，可供合成高级物品。

![方块展示](https://s41.ax1x.com/2026/08/29/pnPAMcD.png)

## 生物图鉴

我们添加了多种生物。这些生物大部分会对你的生存造成威胁，但也不排除有友好的生物。

- [石头守卫](https://www.mcmod.cn/item/695533.html)：石类生物，攻击造成缓慢效果。
- [石头弓箭手](https://www.mcmod.cn/item/695532.html)：远程攻击，可掉落箭矢。
- [石头行商](https://www.mcmod.cn/item/698394.html)：中立生物，可用石币交易。
- **石头傀儡**：会分裂出石头守卫。
- **石之图腾**：BOSS，拥有两个阶段，拥有瞬移、冲击波、连发火球、召唤傀儡、愤怒冲击等技能。

此外，还有**石头浪者**，**迸裂石壳**，**流浪收藏家**，**掠宝者**等各种阵营的生物！

## 建筑与结构

为了使游戏更加丰富，我们添加了多种建筑：

- **石头刷怪笼**：6个变种，分布在不同的地层。
- **废弃驿站**：探索有风险，收益也丰厚。
- **掠宝者营地**：掠宝者在世界各处驻扎，击败他们。
- **古石祭坛**：位于磐石荒地中，是收集BOSS石之图腾召唤物的地方。
